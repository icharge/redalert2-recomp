# Bundled Thai game fonts

These seven `game.fnt` files are provided by the ThaiFontFix project. They combine font sources from Fonts For Red Alert 2 with Thai glyph artwork by THAI RA2 (iCharge). The ThaiFontFix package adds the Thai glyphs to each font.
