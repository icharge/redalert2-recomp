# Bundled fonts

This small runtime set is copied unmodified from `vera20k/src/render/fonts`.
Noto Sans covers Latin, Greek, and Cyrillic; the Thai and Arabic families cover
those scripts; Noto Sans CJK SC provides useful Han, Kana, and Hangul coverage.
The two SIL Open Font License 1.1 notices are included beside the font files.

Source files (font name-table versions): Noto Sans 2.015, Noto Sans Thai 2.001,
Noto Sans Arabic UI 2.011, and Noto Sans CJK SC 2.004. Upstream project:
https://github.com/notofonts

These are assets only. No Vera renderer or implementation source is included.
